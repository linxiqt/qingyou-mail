# 青邮客户端（Windows 1.3.3 / Android 1.3.4）

邮局仍部署在服务器上。Windows 和 Android 应用只连接服务器，不安装 Node.js、SMTP、Rspamd 或本地邮件数据库。邮件、草稿、域名、账号、转发和权限由服务器保存；其他设备刷新后可见更新。

## 使用

1. Windows 将 `Qingyou-Windows-1.3.3-x64.zip` 完整解压后运行 `青邮.exe`，保留同目录的 DLL、资源和子目录；Android 安装 `Qingyou-Android-1.3.4-test.apk`。
2. 填写邮局 HTTPS 地址，例如 `https://210.16.166.94:24785`，随后输入账号和密码。
3. 自签名证书需先点击“查看服务器证书”，通过可信渠道核对 SHA-256 指纹，确认一致后信任。更换证书后需要重新核对。
4. 点击左侧账号或「账号管理」，手机点击底栏「账号」，进入独立账号页添加、切换或退出账号。每个账号使用独立会话，支持保留最多 20 个账号；密码不会保存。

新版导航有随鼠标或触摸位置移动的局部光感，支持系统深色模式与减少动态效果。手机底栏拖动时只预选，松手才切换一次；宽屏自动变为侧栏，并列显示邮件列表与正文。设计依据和项目参数见 `ui/design/android/navigation-reference.json`。

2026-11-02 已通过核对过主机身份的 SSH 获取并验证当前服务器 `https://210.16.166.94:24785` 的证书。其 SHA-256 指纹如下，仅当客户端显示的指纹完全相同才确认信任；服务器更换证书后需重新核对。

```text
0B:BE:B2:B0:D1:C0:37:21:6F:43:37:69:EE:70:EF:8C:9D:F6:62:69:48:DA:C6:CB:5D:1A:FE:8F:E7:0A:B6:A3
```

Windows 根据服务器返回的角色识别管理员，管理员登录后自动打开该服务器的后台窗口。普通邮箱显示邮件客户端；Android 使用完整邮箱地址登录。权限变更和会话失效以服务器响应为准。

## 服务端登录

本版不需要程序激活。客户端连接邮局并验证账号，发件和管理权限以服务端为准。旧客户端请同步升级。

支持收件、搜索、分页、阅读、回复、转发正文、写信、附件、草稿、标星、归档和删除。前台每分钟同步一次，也可手动刷新。没有离线发件队列或后台推送；网络中断时，写操作可能已经提交，需刷新核对后再决定是否重试。

Windows 版本为便携应用，尚未使用商业代码签名；Android 安装包使用测试签名，最低 Android 8，尚未进行真机验收。发布应用商店前需要独立正式签名和设备测试。客户端运行包不包含任何实际登录账号、授权码、AI 密钥或服务器私钥。

## AI 接口文档

Windows 和 Android 左侧「AI 接口文档」可直接阅读与搜索全部 31 个服务器操作，按当前账号的服务器地址生成示例。可复制地址、认证头、请求 URL、JSON、cURL、返回结构、单个接口说明、完整文档，以及完整版/邮件版 OpenAPI JSON，无需另开文档文件。

API Key 为占位符，不会读取或复制登录密码、会话或已有密钥。全局管理员在后台「邮件推送 API」创建专用密钥，将密钥填入外部 AI 运行器的凭据设置。接口直接连接服务器，客户端无需保持运行。复制不会执行接口请求。原「AI 设置」和内置模型调用已替换为此入口。

## 从源码构建

目录 `ui/` 为两端共用界面，`windows/` 为 Electron 宿主，`android/` 为 Android 原生宿主。工具链、缓存、签名私钥和用户数据不属于源码发行包。

Windows（Node.js 24）：

```powershell
cd clients/windows
npm ci
npm run runtime
npm test
npm run build:dir
```

输出在 `windows/dist/win-unpacked/`。构建会复制 `ui/` 最新文件；不需要在用户电脑上运行邮局服务端。`npm run build` 可额外生成单文件便携 EXE，但需要下载 NSIS 等封装工具；本次提供完整目录 ZIP，解压即可运行。

Android（Windows 构建机，JDK 17 或更新版本）：

```powershell
pwsh -File clients/android/build.ps1 -DownloadTools
```

脚本从 Google 官方地址准备固定版本 Android SDK，并校验下载摘要，然后执行 Java、DEX、资源打包及 APK 签名验证。输出在 `android/dist/`；测试签名仅保存在构建机 `android/.signing/`，勿作为正式分发密钥使用。
