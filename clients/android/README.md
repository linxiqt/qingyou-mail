# 青邮 Android 客户端

这是邮局的安卓客户端，不会在手机上安装邮局服务。默认连接 `https://210.16.166.94:24785`，也可以填写自己的 HTTPS 服务器。账号、邮件、转发和权限由服务器负责。

## 安装与使用

安装 `dist/Qingyou-Android-1.3.4-test.apk`，要求 Android 8.0（API 26）或更新版本及正常更新的 Android System WebView。此 APK 使用开发测试证书签名，尚未用于应用商店发布。后续正式发布请使用自己的长期签名密钥，保持升级签名一致。

1.3.4 接入服务端统一授权：必须连接并验证登录后才能使用；服务端正式授权有效时才能写信、发送、写入草稿和进行业务管理。授权失效后仍可接收及阅读，未提交的草稿保留。客户端不需要单独激活，管理员在服务端恢复授权后点「重新检查」即可。界面和 Android 原生传输层都会校验，维护源码版不能解锁发送与管理。

1.3.2 按手机参考图重新设计：蓝白渐变邮箱总览、四格快捷卡片、圆角头像邮件列表与底部导航。统计仅显示当前账号的服务器数据，未加载显示「—」，没有邮件显示 0。顶部头像与底部「账号」均可切换邮箱；收件箱可筛选未读或标星邮件。支持深色模式、小屏、横屏与减少动画设置。

1.3.3 将「账号」与「写邮件」做成独立页面。手机浮动透明底栏支持滑动预选、松手后按最终位置切页；拖动期间页面、滚动位置和无障碍当前项保持不变。栏外释放、取消、失焦均取消预选。光效只在导航内部跟随触点，离开后淡出，支持深色和减少动态效果设置。宽度达到 700px 时变为左侧导航，1050px 时并列显示邮件列表和正文。

系统返回先关闭弹窗，再退出账号页、写信页或邮件详情；未保存的草稿仍会提示确认。界面不依赖外部图片或字体，邮件列表沿用服务器分页与搜索防抖。Windows 同步获得独立账号页与侧栏光效，服务器部署不受改版影响。

官方参考与本项目参数的边界记录于 `../ui/design/android/navigation-reference.json`：参考华为公开的材质、交互响应与多设备适配原则；光斑尺寸、透明度、时长、断点和松手提交规则均为项目实现选择。

用完整邮箱地址和密码登录，可添加多个邮箱并切换。每个账号拥有独立 Cookie、CSRF 和服务器地址。不会保存密码；登录会话使用 Android Keystore 的 AES-GCM 密钥加密后存于应用私有目录，禁止系统备份。退出会尝试撤销服务器会话并清除本机账号；断网时只能先移除本机账号，服务器会话仍按服务器期限过期。

手机端为普通邮箱界面。管理账号 `admin` 请在 Windows 客户端中使用管理员界面。手机端包含「AI 接口文档」，支持系统剪贴板复制和按账号服务器生成请求示例。附件由系统文件选择器导入或保存，不申请广泛存储权限。邮件正文默认显示安全的纯文本，不运行来信中的脚本或远程图片。

证书不受信任时，先查看 SHA-256 指纹，通过可信渠道与服务器管理员核对，点击信任后还需在 Android 原生弹窗再次确认。只对该 HTTPS 地址固定该证书；证书变化、过期或主机名不符都会拒绝连接。不会跳过 SSL 错误，不会跟随携带登录状态的重定向。

## Windows 上构建 APK

需要 JDK 17 或更新版本和 PowerShell 7。执行：

```powershell
pwsh -File clients/android/build.ps1 -DownloadTools -JavaHome 'C:/Program Files/Java/jdk-25.0.4'
```

`-DownloadTools` 从 Google 官方仓库下载固定的 SDK Platform 35 与 Build Tools 35，并校验官方仓库发布的 SHA1；请遵守 [Android SDK 许可](https://developer.android.com/studio/terms)。工具位于本项目 `.toolchain`，不会修改系统环境变量或安装 Android Studio。之后可以省略 `-DownloadTools`。

构建复制 `../ui` 的页面和脚本，替换为 Android 原生桥，使用 javac、D8、AAPT2、zipalign 和 apksigner 输出 APK 与 SHA256。`build/`、`.toolchain/`、`.signing/` 不属于源码交付包，尤其不要分发签名私钥。

## 验证范围

已完成 Java 编译、DEX 生成、APK 资源打包及 v2/v3 签名校验。`test/TransportTest.java` 用临时本机 HTTPS 服务检查 Cookie/CSRF 隔离、TLS 固定与主机名验证、重定向拒绝和接口路径边界。完整邮箱业务由服务器测试覆盖。

复现原生网络测试（只连接本机临时 HTTPS 服务，不使用真实邮箱凭据）：

```powershell
pwsh -File clients/android/test.ps1 -DownloadTestDependency -JavaHome 'C:/Program Files/Java/jdk-25.0.4'
```

测试使用固定版本的 JVM JSON 依赖并校验 SHA256，该依赖不会打进 APK。每次生成短期本机测试证书，另验证响应中断后的发送状态提示，避免不确定情况下提示重复发送。

当前构建环境没有连接 Android 真机或模拟器，未声称已完成真机安装、系统文件选择器和键盘交互验收。发布前需在目标设备检查这些交互及 Android WebView 版本兼容性。

隔离界面回归可运行 `node clients/ui/test/browser-smoke.cjs`：覆盖 320–1180px 与横屏，检查账号隔离、总览计数、搜索筛选、错误重试、返回滚动位置、草稿保护、深色模式及 Windows 原有工作流。导航用真实浏览器触摸、鼠标和键盘事件验证多指隔离、最终位置提交、栏外取消、补发点击拦截、侧栏原生滚动与 Touch Events 回退。测试不会发送真实邮件，截图与报告在 `../ui/test/.artifacts/`。

共享接口约定见 `../API.md`；原生方法通过 `bridge.js` 暴露。网络请求只能访问当前账号服务器的 `/api/client` 接口，WebView 只加载随 APK 打包的资源，没有通用网络代理或执行系统命令功能。
